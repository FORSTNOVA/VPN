# Phase29: complete path-domain state authority

The same long-lived service handle now owns path configuration, busy/status/results/retry state, monitor generation, round lease, previous demand observations and per-label throttle time tokens, alongside traffic state. One epoch/revision/command/Ack protocol covers both domains. Required persistent ABI v2 capabilities are checked before selection; older DLLs select Go for the entire authority. Existing short workflow exports remain separately compatible. Default Go is unchanged.

Production app.pathBusy/app.pathStatus and live settings.PathChecks have been removed. A temporary settingsDocument projects the current authoritative configuration into the original settings.json shape; ordinary settings/subscription snapshot writes cannot overwrite path configuration. Partial JSON decoding, nil/empty arrays, original defaults and save ordering are retained. Failed configuration save leaves the new in-memory configuration and does not restart monitoring. No second config file or writable long-lived Go configuration mirror is added.

Path and monitor planners, including Go planner fallback, operate the same authority. Actual channel/ticker/worker/mutex/controller/probe/health/region and pin resources remain Go. Twenty-one typed path commands maintain domain state; existing Rust workflow planners still make round/normalization/recovery decisions. Single-result pathPassed and codec/platform facts remain explicit Go boundaries. Standalone demand helper calls preserve their explicit caller-owned Previous-map contract; production monitor previous/throttle state resides in the authority.

Queued admission retains channel identity plus the first lock atomically. An admitted round lease survives monitor revoke/restart or cancel-recovery, preserving existing in-flight semantics. Baseline/legacy versus recovery cleanup remains different; no REJECT or cross-region switching is added. Old loops check identity before reading authority. Full service shutdown revokes path and traffic cancellation channels before closing the authority; recovered errors are reported explicitly instead of allowing stale workers to reopen a handle or panic out of the process.

Time remains Go monotonic time.Time behind immutable tokens. Traffic baseline, path report time and active label throttle tokens share a bounded ledger. Generation revoke releases observation/throttle memory but not an already-admitted round. The full checkpoint validates both domains and last command fields. Controlled internal handoff rejects active busy/lease state, pending commands or missing tokens. It remains a tested internal capability, not automatic production failover or a public settings action.

Path payloads and tables have explicit byte/count limits. Read/Rate/Status/Export may grow a reused buffer on a capacity response because they are read-only; Apply validates its fixed reply capacity before mutation and is never replayed for buffer growth. Invalid state/uncertain commit fails closed. A later successful command cannot conceal an unresolved earlier one.

Verification covers native ownership across requests, Go planner with native owner, configuration/document cross-writes, staged GET and queued worker barriers, cleanup distinctions, 30-second edges, time-token reuse, command reply faults and checkpoint corruption. Flutter sources were read-only checked for the unchanged path-checks routes/settings/status/limits fields; no frontend or device runtime test is claimed. All network, listeners, timers, persistence and probes used in tests are fake or synthetic TempDir fixtures. No real VPN, node switch, system network change or user database was used.

Focused verification after review: 497 Rust tests; 1,600 shared path/traffic randomized authority steps; 334 full Rust workflow calls with native ownership and zero normal continuation recovery; four Go-planner/native-owner cases; five settings-document tests explicitly assert native/default/disabled/missing selection. Fault checks cover 42 action-delivery sequences and 23 checkpoint field corruptions, old-DLL whole-instance fallback and active-lease handoff rejection. Thirty thousand native At/Throttle commands validate bounded clocks. AlertID maximum wrap is Rust-unit coverage, not claimed actual-DLL coverage. Final review fixed response-read failures becoming empty success and guarded worker cleanup panics escaping; new no-network tests cover both. Full aggregate and delivery status are tracked separately.
