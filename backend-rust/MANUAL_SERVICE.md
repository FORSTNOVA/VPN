# Phase19: manual-node lifecycle

Opt-in `SMARTVPN_RUST_MANUAL_FLOW=1` on a `rustcore` Windows amd64 build with an absolute trusted core DLL selects Rust planning. Default Go and same-continuation recovery remain. This stage covers load/save/list/preview/add/delete/provider-update orchestration, not the replacement of URI/JSON/YAML codecs or OS/storage implementations.

Rust plans validation order, name conflicts, filtering, state updates and rollback, provider file steps, and result selection. Proxy graphs, raw URI/credentials, serialized data and real resources remain in Go. Do not treat this as a secret-storage migration: existing JSON settings/provider formats remain unchanged.

Compatibility includes nil-versus-empty slices, skipping encoding without a store, all-or-nothing load decode failure, no load dedup/reparse, preview name override without changing Proxy.name, running/duplicate priority, add truncation after save failure, delete restoring its original slice on save failure, and provider failure retaining the already saved change. Deleting the last node preserves an empty non-nil list. Empty-provider removal only ignores errors matching NotExist. Nonempty provider uses YAML, mkdir 0700, temp write 0600, rename; failure does not introduce new temp-file cleanup.

Tests must use fake kernel/network/storage ports or independent TempDir/TempDB. Actual VPN, user databases and node credentials are not used. Default, disabled and missing-DLL selectors must run successful lifecycle checks, in addition to strict actual-DLL trace/result comparisons and fault/no-replay tests. See stage validation records for final counts and limits. Android cross-compilation is not device/runtime verification.

Verified offline: 242 Rust tests; 206 default Go safe tests; 1,767 strict actual-DLL comparisons and four independent legacy object-identity contracts, zero recovery. Seven TempDir provider cases and successful default/disabled/missing-DLL selector lifecycles passed. File modes are checked as requested arguments, not claimed as Windows POSIX permission enforcement. Fault suite includes 42 ABI boundaries, 20 effect panics, finalizer panic, 64-session capacity/1,200 cancellations, and 50,001-node load exceeding 100,000 effects without repeated decode or recovery. Function-valued exceptional graphs deliberately use the same Go continuation and are counted separately from normal Rust cases. Review found and fixed both production graph-identity drift and a visited-slice comparison key missing length.
